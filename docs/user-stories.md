# PulseCRM User Stories

## Authentication

- As a user, I want to log in securely so that I can access the CRM.
- As a user, I want to log out so that my account remains secure.
- As a user, I want to reset my password if I forget it.
- As a user with access to more than one organisation, I want to work only inside the organisation I selected.

## CEO

- As a CEO, I want to view company-wide dashboard metrics and reports.
- As a CEO, I want to view organisation-wide customers, pipeline, tasks, and support cases.
- As a CEO, I want to view the shared inbox where my permissions allow it.
- As a CEO, I want to see overdue tasks and conversations needing replies.
- As a CEO, I want access limited to organisations I belong to.

## CRM Admin

- As a CRM Admin, I want to manage users and roles within an organisation.
- As a CRM Admin, I want to review duplicate suggestions.
- As a CRM Admin, I want to merge duplicate customer records.
- As a CRM Admin, I want to reverse a merge when it was incorrect.
- As a CRM Admin, I want to manage imports.
- As a CRM Admin, I want to manage integrations.
- As a CRM Admin, I want to review failed integration events.
- As a CRM Admin, I want to restore archived records.
- As a CRM Admin, I want to view audit logs.

## Sales Representative

- As a Sales Representative, I want to view assigned leads and opportunities.
- As a Sales Representative, I want to manage my personal tasks.
- As a Sales Representative, I want to view related customer and company context for my work.
- As a Sales Representative, I want to convert a qualified lead into an opportunity without duplicating the customer.
- As a Sales Representative, I want to see opportunities with no next action.
- As a Sales Representative, I want inbox access only when I have an additional role or explicit permission.

## Inbox Agent

- As an Inbox Agent, I want to view the shared inbox.
- As an Inbox Agent, I want to reply to customers.
- As an Inbox Agent, I want to add internal notes.
- As an Inbox Agent, I want to see when another user is currently replying.
- As an Inbox Agent, I want to select exact messages in a conversation.
- As an Inbox Agent, I want to create a task, lead, opportunity, support case, or internal note from selected messages.
- As an Inbox Agent, I want to link selected messages to existing CRM work.
- As an Inbox Agent, I want to view linked work beside the conversation.
- As an Inbox Agent, I want to handle channel-only customer profiles.
- As an Inbox Agent, I want to suggest possible duplicate matches.
- As an Inbox Agent, I want read and unread state to apply to me without changing another user's read state.

## Customer Management

- As an authorised user, I want to create a channel-only customer profile when only a provider identity is known.
- As an authorised user, I want to progressively add phone, email, address, and preference details.
- As an authorised user, I want to view a customer's complete timeline.
- As an authorised user, I want to search for customers using name, phone, email, provider identity, or company.
- As an authorised user, I want to filter customers by source, company, archive state, and date.
- As an authorised user, I want to view possible duplicate suggestions.

## Companies And Contacts

- As an authorised user, I want to create company records.
- As an authorised user, I want to connect individual contacts to a company.
- As an authorised user, I want to mark one contact as primary where needed.
- As an authorised user, I want to view leads, opportunities, tasks, and support cases related to a company.

## Leads

- As an authorised user, I want to create a lead connected to an existing customer or company.
- As an authorised user, I want leads to be created from incoming enquiries without creating duplicate customers.
- As a Sales Representative, I want to update the status of a lead.
- As a Sales Representative, I want to add notes and activities to a lead.
- As a Sales Representative, I want to schedule a follow-up for a lead.
- As a Sales Representative, I want to qualify or reject a lead.
- As a Sales Representative, I want to convert a qualified lead into an opportunity.

## Opportunities

- As an authorised user, I want to create a sales opportunity.
- As an authorised user, I want to connect an opportunity to a customer or company.
- As a Sales Representative, I want to move opportunities between pipeline stages.
- As a Sales Representative, I want to record expected value and closing date.
- As a Sales Representative, I want to mark an opportunity as won or lost.
- As a Sales Representative, I want to record why an opportunity was lost.

## Tasks And Follow-Ups

- As an authorised user, I want to create tasks.
- As an authorised user, I want to assign tasks to individuals.
- As an authorised user, I want to set due dates, priorities, and statuses.
- As an authorised user, I want to connect tasks to customers, companies, leads, opportunities, support cases, conversations, or exact source messages.
- As an authorised user, I want to receive reminders for upcoming tasks.
- As an authorised user, I want to view overdue and completed tasks.

## Support Cases

- As an authorised user, I want to create a support case.
- As an authorised user, I want to link a support case to a customer or company.
- As an authorised user, I want support cases to have automatically generated case numbers.
- As an authorised user, I want to update support case status.
- As an authorised user, I want to set support case priority.
- As an authorised user, I want to link exact source messages to a support case.

## Imports, Integrations, And Reports

- As a CRM Admin, I want to import customers from CSV files.
- As a CRM Admin, I want to review failed import rows.
- As a CRM Admin, I want to review failed integration events.
- As a CRM Admin, I want to replay failed integration events where safe.
- As an authorised user, I want reports to show only data I am permitted to view.
- As an authorised user, I want to export reports where my permissions allow it.
