# PulseCRM User Stories

## Authentication

- As a user, I want to log in securely so that I can access the CRM.
- As a user, I want to log out so that my account remains secure.
- As a user, I want to reset my password if I forget it.
- As an administrator, I want to activate or deactivate user accounts.

## Dashboard

- As a user, I want to see a summary of customers, leads, sales opportunities, tasks, and complaints.
- As a user, I want to see my upcoming and overdue tasks.
- As a manager, I want to see team performance information.
- As a sales employee, I want to see leads and opportunities assigned to me.

## Customer Management

- As a user, I want to create a customer record.
- As a user, I want to view a customer’s complete profile.
- As a user, I want to edit customer information.
- As a user, I want to search for customers using their name, phone number, email address, or company.
- As a user, I want to filter customers by source, status, owner, or date.
- As a user, I want to view all customer activity in one timeline.
- As an authorised user, I want to merge duplicate customer records.

## Companies and Contacts

- As a user, I want to create company records.
- As a user, I want to connect individual contacts to a company.
- As a user, I want to select a primary contact for a company.
- As a user, I want to view leads, opportunities, tasks, and complaints related to a company.

## Unified Inbox

- As a user, I want to view customer conversations from different channels in one inbox.
- As a user, I want to see the source channel of each conversation.
- As a user, I want to assign a conversation to an employee.
- As a user, I want to mark a conversation as open, pending, or resolved.
- As a user, I want to create a lead, task, complaint, or opportunity from a conversation.
- As a user, I want to view the customer profile beside the conversation.

## Lead Management

- As a user, I want to create a lead manually.
- As a user, I want leads to be created from incoming enquiries.
- As a manager, I want to assign leads to employees.
- As a sales employee, I want to update the status of a lead.
- As a user, I want to add notes and activities to a lead.
- As a user, I want to schedule a follow-up for a lead.
- As a user, I want to qualify or reject a lead.
- As a user, I want to convert a qualified lead into a customer and sales opportunity.
- As a manager, I want to view lead conversion performance.

## Sales Opportunities

- As a user, I want to create a sales opportunity.
- As a user, I want to connect an opportunity to a customer or company.
- As a user, I want to move opportunities between pipeline stages.
- As a user, I want to record an expected value and closing date.
- As a user, I want to mark an opportunity as won or lost.
- As a user, I want to record why an opportunity was lost.
- As a manager, I want to view the total value of the sales pipeline.
- As a manager, I want to view sales conversion rates.

## Tasks and Follow-Ups

- As a user, I want to create tasks.
- As a manager, I want to assign tasks to employees.
- As a user, I want to set due dates, priorities, and statuses.
- As a user, I want to connect tasks to customers, leads, opportunities, or complaints.
- As a user, I want to receive reminders for upcoming tasks.
- As a user, I want to view overdue and completed tasks.
- As a user, I want to record calls, meetings, emails, and follow-up activities.

## Complaints and Service Requests

- As a user, I want to create a complaint or service request.
- As a user, I want to link a complaint to a customer.
- As a manager, I want to assign complaints to support employees.
- As a support employee, I want to update the status and priority of a complaint.
- As a support employee, I want to add notes, files, and responses.
- As a support employee, I want to record how a complaint was resolved.
- As a user, I want to view the full complaint history.

## Customer Identity Matching

- As a user, I want the system to match customers using phone numbers and email addresses.
- As a user, I want to be warned before creating a duplicate customer.
- As an authorised user, I want to review possible duplicate records.
- As an authorised user, I want to merge duplicate records without losing customer information.

## Reports

- As a manager, I want to view customer-source reports.
- As a manager, I want to view lead conversion reports.
- As a manager, I want to view sales pipeline reports.
- As a manager, I want to view employee and team performance reports.
- As a manager, I want to filter reports by date, source, owner, channel, or status.
- As an authorised user, I want to export reports as CSV files.

## Integrations

- As an administrator, I want to connect website forms to the CRM.
- As an administrator, I want to configure WhatsApp integration.
- As an administrator, I want to configure Instagram and Facebook integrations.
- As an administrator, I want to enable or disable integrations.
- As an administrator, I want to view failed integration operations.

## CSV Import

- As a user, I want to upload customer information using a CSV file.
- As a user, I want to map CSV columns to CRM fields.
- As a user, I want to preview records before importing them.
- As a user, I want the system to detect invalid or duplicate records.
- As a user, I want to see which records were successfully imported.
- As a user, I want to download a report showing failed records.

## Notifications

- As a user, I want to receive notifications when a lead is assigned to me.
- As a user, I want to receive notifications when a conversation is assigned to me.
- As a user, I want to receive reminders for upcoming and overdue tasks.
- As a support employee, I want to receive notifications for new complaints.
- As an administrator, I want to receive notifications when an integration fails.
- As a user, I want to mark notifications as read or unread.

## Roles and Permissions

- As an administrator, I want to create and manage users.
- As an administrator, I want to assign roles to users.
- As an administrator, I want to control which features each role can access.
- As a manager, I want to view records belonging to my team.
- As an employee, I want to access only the records and actions permitted by my role.

## Audit Logs

- As an administrator, I want to view important actions performed in the system.
- As an administrator, I want to see who changed a record and when it was changed.
- As an administrator, I want customer merges, user changes, imports, and integration activity to be recorded.
- As an administrator, I want audit logs to be protected from unauthorised users.

## Files and Attachments

- As a user, I want to upload files to customer profiles.
- As a user, I want to attach files to tasks, opportunities, complaints, and conversations.
- As a user, I want to view and download permitted attachments.
- As an authorised user, I want to delete attachments.
