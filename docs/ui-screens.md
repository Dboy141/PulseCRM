# PulseCRM UI Screens

## Overview

This document lists the main screens required for the PulseCRM MVP. The final appearance will follow the approved mock designs.

## 1. Login Page

The login page allows authorised employees to access the CRM.

Main elements:

- Email address field.
- Password field.
- Login button.
- Forgotten-password link.
- Error message for invalid login details.

## 2. Dashboard

The dashboard provides an overview of important CRM information.

Main elements:

- Total customers.
- New leads.
- Qualified leads.
- Sales pipeline value.
- Open support cases.
- Upcoming tasks.
- Overdue tasks.
- Recent customer activity.
- Recent conversations.

## 3. Unified Inbox

The unified inbox displays customer conversations from different channels.

Main elements:

- Conversation list.
- Channel indicator.
- Search and filters.
- Assigned employee.
- Conversation status.
- Message area.
- Customer information panel.
- Button to create a lead, task, opportunity, or support case.

## 4. Customers Page

The customers page displays all customer records.

Main elements:

- Customer table.
- Search bar.
- Source filter.
- Status filter.
- Owner filter.
- Add-customer button.
- Pagination.

## 5. Customer Profile

The customer profile displays all information connected to one customer.

Main elements:

- Personal and contact information.
- Assigned employee.
- Customer source.
- Communication preferences.
- Conversations.
- Leads.
- Opportunities.
- Tasks.
- Support cases.
- Notes.
- Files.
- Activity timeline.
- Edit and merge actions.

## 6. Companies Page

The companies page displays business customer records.

Main elements:

- Company list.
- Search and filters.
- Company name.
- Industry.
- Primary contact.
- Assigned employee.
- Add-company button.

## 7. Leads Page

The leads page displays potential customers.

Main elements:

- Lead list.
- Search bar.
- Status filter.
- Source filter.
- Assigned-user filter.
- Lead score.
- Add-lead button.
- Qualification and conversion actions.

## 8. Lead Details Page

The lead details page displays information about one lead.

Main elements:

- Contact details.
- Lead source.
- Lead status.
- Assigned employee.
- Lead score.
- Notes and activities.
- Follow-up tasks.
- Qualify button.
- Convert button.
- Mark-lost button.

## 9. Sales Pipeline

The sales pipeline displays opportunities according to their current stage.

Main elements:

- Pipeline columns.
- Opportunity cards.
- Opportunity value.
- Customer or company.
- Assigned owner.
- Expected closing date.
- Drag-and-drop stage movement.
- Won and lost actions.

## 10. Opportunity Details

The opportunity details page displays information about one potential sale.

Main elements:

- Opportunity name.
- Customer or company.
- Pipeline stage.
- Expected value.
- Win probability.
- Expected closing date.
- Assigned owner.
- Notes.
- Tasks and follow-ups.
- Mark-won and mark-lost actions.

## 11. Tasks Page

The tasks page displays employee activities and follow-ups.

Main elements:

- Task list.
- Status filter.
- Priority filter.
- Assigned-user filter.
- Due-date filter.
- Overdue-task indicator.
- Add-task button.
- Complete-task action.

## 12. Support Cases Page

The support cases page displays complaints and service requests.

Main elements:

- Case number.
- Customer.
- Subject.
- Priority.
- Status.
- Assigned employee.
- Created date.
- Add-case button.
- Resolve and reopen actions.

## 13. Reports Page

The reports page displays CRM performance information.

Main elements:

- Customer-source report.
- Lead-conversion report.
- Sales-pipeline report.
- Team-performance report.
- Task report.
- Support-case report.
- Date and employee filters.
- Tables and charts.
- CSV export button.

## 14. Integrations Page

The integrations page allows administrators to manage connected platforms.

Main elements:

- Website integration.
- WhatsApp integration.
- Instagram integration.
- Facebook integration.
- Connection status.
- Enable or disable actions.
- Test-connection button.
- Integration-error information.

## 15. User Management Page

The user-management page allows administrators to manage employee accounts.

Main elements:

- User list.
- Name and email.
- Role.
- Team.
- Account status.
- Add-user button.
- Edit-user action.
- Activate or deactivate action.

## 16. Settings Page

The settings page allows authorised users to configure the CRM.

Main elements:

- Organisation settings.
- Roles and permissions.
- Sales pipeline stages.
- Lead statuses.
- Support-case categories.
- Notification preferences.
- Communication preferences.
- Import and export settings.

## 17. Notifications Panel

The notifications panel displays important system alerts.

Main elements:

- New assignments.
- Upcoming tasks.
- Overdue tasks.
- New support cases.
- Integration failures.
- Read and unread status.
- Mark-all-as-read action.

## Navigation

The main sidebar should include:

- Dashboard.
- Inbox.
- Customers.
- Companies.
- Leads.
- Sales Pipeline.
- Tasks.
- Support Cases.
- Reports.
- Integrations.
- Settings.

## Responsive Design

The application should work on:

- Desktop computers.
- Tablets.
- Mobile devices.

Desktop design will be prioritised for the initial MVP.
